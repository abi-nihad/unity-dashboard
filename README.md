# UNITY Dashboard

This repository contains the UNITY Dashboard web app.

## Prerequisites
- Git installed
- A remote repository (GitHub, GitLab, etc.) created or available

## First-time Git setup (if repository not initialized)
```bash
git init
git add .
git commit -m "Initial commit: UNITY Dashboard v22.62"
# Replace with your remote URL
git remote add origin https://github.com/<your-org>/<your-repo>.git
git branch -M main
git push -u origin main
```
